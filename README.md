# Mohd Shariq Portfolio

A beginner-friendly static portfolio website for Mohd Shariq, QA Engineer.

## Files

- `index.html` - home page
- `about.html` - background, skills, and experience
- `projects.html` - QA project cards
- `contact.html` - contact form and social links
- `certificates.html` - about my certificates
- `styles.css` - shared responsive styles
- `script.js` - mobile navigation and form feedback

## Run locally

Open `index.html` directly in a browser. No build step or dependencies are required.

Replace the placeholder GitHub and LinkedIn URLs in the HTML files with your profile links before publishing.
